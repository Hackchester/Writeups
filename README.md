# Hackchester Writeups

Welcome to the **Hackchester Writeups** repo! This is the central hub where our society members share their knowledge, document their CTF solves, and publish writeups. 

Whenever a [Pull Request](https://docs.github.com/en/pull-requests/reference/pull-requests) is merged here, it automatically triggers a build and publishes the latest changes to our official Hackchester website. 🚀
